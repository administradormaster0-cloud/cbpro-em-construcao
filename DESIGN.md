# CBPRO design

The active construction is `data/cbpro-reconstruction`, assembled from route overrides in `src/reconstruction/routes`, the split complete runtime, the semantic home client and the reconstruction styles. The incomplete Vite application and public Hostinger release are not the delivery target.

The approved composition leads with a championship and full trophy, with programming alongside it. Blue and green remain the CBPRO colors; Phudu carries sporting headlines and Barlow carries readable body text. The latest request asks for more impact on this same composition. The home now uses a larger trophy and display hierarchy, an editorial news layout and clearer ranking numerals. Existing records, destinations and selectable dark mode are preserved.

Authenticated surfaces operate as tools: identifiable controls, readable fields, visible loading/error/empty states and clear permissions. Public surfaces use prepared Supabase data; private records must stay scoped to the current authorized session. Prepared data is a performance mechanism, not permission to display expired records as current.
